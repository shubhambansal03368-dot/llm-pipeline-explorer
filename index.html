Core Pillars of the LLM Representation Pipeline

📖 1. Tokenization

Converting unstructured text strings into discrete atomic units (words, punctuation, or subword tokens). Models cannot process raw strings directly without tokenization.

📚 2. Vocabulary

The fixed dictionary of all allowable tokens known to the model. Every entry has a designated integer ID from 0 to |V|−1.

🔢 3. Token IDs (Not Embeddings!)

Arbitrary scalar integers. Token ID 42 is not "twice" Token ID 21. Scalar integer IDs carry zero geometric or semantic relationship.

📦 4. Dense Embeddings (v ∈ ℝᵈ)

The Embedding Lookup Matrix E ∈ ℝ^(|V| × d) maps each Token ID to a continuous dense vector. In production LLMs, d is 4,096 to 12,288 dimensions.

🧭 5. High-Dimensional Vector Space

The continuous geometric manifold where spatial angles and distances correspond to conceptual relationships. 3D projection (PCA) makes this visually tangible.

📐 6. Cosine Similarity (cos θ)

Measuring the directional angle θ between vectors via (u · v) / (||u|| · ||v||), ensuring word frequency or vector scale does not distort conceptual alignment.
